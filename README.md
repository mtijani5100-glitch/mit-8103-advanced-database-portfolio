# MIT 8103 Advanced Database Systems Portfolio

## Case Study

LedgerSpring Digital Bank (LSDB) is a fictional Nigerian
digital banking platform.

## Objective

To design, implement, test, optimise, and document an
advanced database system using a consistent financial
services case study.

## Portfolio Activities

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Databases

## Technology

- PostgreSQL
- MongoDB
- SQL
- Git and GitHub
- diagrams.net

## Repository Structure

Each portfolio directory contains implementation files,
documentation, and supporting evidence.

## Academic Integrity

All test data is synthetic. References and AI assistance
will be documented where applicable.
